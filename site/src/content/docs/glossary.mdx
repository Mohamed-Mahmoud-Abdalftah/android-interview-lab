# Technical Glossary

| Term | Practical Definition |
|---|---|
| `Source of Truth` | The single canonical location that the rest of the application considers authoritative for state. |
| `Structured Concurrency` | Concurrency where every asynchronous operation has a clear lifecycle owner and parent scope. |
| `Idempotency` | The property where retrying an identical request produces no duplicate side effects. |
| `Backpressure` | Flow control when a producer emits faster than a consumer can process, requiring buffering, dropping, or suspension. |
| `Type Erasure` | The JVM mechanism where generic type arguments are removed at compile time and unavailable at runtime. |
| `WAL` | Write-Ahead Logging; SQLite write log format where mutations append sequentially before checkpointing into the database. |
| `UDF` | Unidirectional Data Flow; user actions flow inward as events, and state flows outward as immutable snapshots. |
| `Unknown Outcome` | A network condition where a request may have succeeded remotely but the client received no acknowledgment, requiring reconciliation before retrying. |
