# قاموس سريع

| المصطلح | المعنى العملي |
|---|---|
| `Source of Truth` | المكان اللي بقية النظام تعتبر حالته المرجع الأساسي للقراءة. |
| `Structured Concurrency` | كل شغل asynchronous له owner واضح وعمر مرتبط بالـscope. |
| `Idempotency` | تكرار نفس الطلب بنفس الهوية ما يعملش أثر business جديد. |
| `Backpressure` | المنتج أسرع من المستهلك، فلازم تحدد buffering أو إسقاط أو إبطاء. |
| `Type Erasure` | أغلب generic arguments مش بتفضل متاحة كاملة وقت JVM runtime. |
| `WAL` | سجل كتابة تستخدمه SQLite قبل دمج الصفحات في الملف الرئيسي. |
| `UDF` | الأحداث تدخل في اتجاه، والـstate الجديدة تخرج في اتجاه واحد. |
| `Unknown Outcome` | العملية قد تكون حصلت لكن الرد ضاع؛ لازم reconcile قبل retry مؤثر. |

استخدم البحث بكلمة عربية أو الاسم الإنجليزي للوصول للدرس الكامل والسياق العملي.
