استخدم صفحات المواضيع وحدد هدفك اليومي من الأسئلة في [لوحة التحكم](../). قسّم وقتك بين الأسئلة الجديدة ومراجعة البطاقات المستحقة.

## 7 أيام · مراجعة سريعة ومركزة

| اليوم | التركيز |
|---|---|
| 1 | كوتلن، أساسيات أندرويد، إدارة الذاكرة |
| 2 | الـ Coroutines والـ Flow |
| 3 | المعمارية، مبادئ SOLID، أنماط التصميم، حقن التبعيات |
| 4 | واجهات Compose، قواعد البيانات، العمليات الخلفية |
| 5 | الأمان، سيناريوهات الدفع، تصميم الأنظمة (System Design) |
| 6 | تقسيم الموديولات، البناء والإطلاق، الاختبارات، الـ CI/CD |
| 7 | الخوارزميات، القيادة التقنية، جلسات محاكاة ونقاط الضعف |

## 14 يوماً · تدريب متوازن

خصص الأيام 1–5 للمرحلة الأولى، والأيام 6–8 للمرحلة الثانية، والأيام 9–11 للمرحلة الثالثة، والأيام 12–13 للمرحلة الرابعة، واليوم 14 للمرحلة الخامسة مع جلسة محاكاة كاملة.

## 30 يوماً · تعمق شامل

خصص يوماً كاملاً لكل موضوع من الـ 21 موضوعاً. استخدم الأيام 22–26 للمسارات المترابطة (Coroutines → Flow → Compose; Lifecycle → Memory → Background Work; Architecture → SOLID → DI → Modules; Security → Payments → System Design; Testing → CI/CD → Release). وخصص الأيام 27–30 للمراجعة المتباعدة ومقابلتين تجريبيتين.
