# قاموس المصطلحات

| المصطلح | المعنى العملي في النظام |
|---|---|
| `Source of Truth` | المكان الوحيد المعتمد الذي يعتبره بقية النظام المرجع الأساسي للقراءة وحالة التطبيق. |
| `Structured Concurrency` | تزامن منظم حيث كل عملية غير متزامنة تمتلك مالكاً صريحاً وعمراً مرتبطاً بنطاق الـ Scope. |
| `Idempotency` | خاصية تضمن أن إعادة إرسال نفس الطلب بنفس المعرف لا ينتج عنها أي تأثير جانبي مضاعف. |
| `Backpressure` | التحكم في تدفق البيانات عندما ينتج المصدر أسرع من قدرة المستهلك، مما يتطلب تخزيناً مؤقتاً أو إسقاطاً أو تعليقاً. |
| `Type Erasure` | مسح الأنواع في الـ JVM حيث تُحذف معاملات الـ Generics وقت الـ Compile وتغيب عن وقت التشغيل. |
| `WAL` | سجل الكتابة المسبقة (Write-Ahead Logging) في SQLite لتسجيل التعديلات قبل دمجها في قاعدة البيانات. |
| `UDF` | تدفق البيانات أحادي الاتجاه؛ الأحداث تتدفق للداخل، والحالة تتدفق للخارج كنسخ غير قابلة للتعديل. |
| `Unknown Outcome` | حالة عدم اليقين حيث قد تكون العملية نجحت على السيرفر لكن الرد فُقد؛ تتطلب تسوية قبل إعادة المحاولة. |

استخدم البحث في الشريط العلوي للوصول إلى تفاصيل كل مصطلح وسياقه العملي في المقابلات.
