## طريقة المذاكرة

1. اقرأ الـmental model وتتبع التنفيذ خطوة بخطوة.
2. توقّع نتيجة الكود وسيناريو الفشل قبل تشغيل الاختبار.
3. جاوب السؤال بالمصري طبيعي، واستخدم المصطلحات وأسماء الـAPIs بالإنجليزي.
4. نفّذ الـlab وسجّل الدرس أو السؤال مكتمل من نفس الصفحة.

> البيانات الشخصية، العلامات والملاحظات بتفضل في `localStorage` داخل المتصفح. التصدير والاستيراد JSON بيخلّيك تنقل تقدمك من غير backend.
