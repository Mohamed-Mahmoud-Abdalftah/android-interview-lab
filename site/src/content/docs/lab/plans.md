title: Study plans
description: Seven, fourteen, and thirty day Android interview study schedules
---

Use the topic pages and set your daily question goal on the [Lab dashboard](../). Spend part of each session on first attempts and part on due reviews. These schedules do not imply source-only answers have been reviewed.

## 7 days · focused refresh

| Day | Focus |
|---|---|
| 1 | Kotlin, Android fundamentals, memory |
| 2 | Coroutines and Flow |
| 3 | Architecture, SOLID, patterns, DI |
| 4 | Compose, data, background work |
| 5 | Security, payments, system design |
| 6 | Modularization, build/release, testing, CI/CD |
| 7 | Algorithms, leadership, timed mock and weak areas |

## 14 days · balanced practice

Spend days 1–5 on Phase 1, days 6–8 on Phase 2, days 9–11 on Phase 3, days 12–13 on Phase 4, and day 14 on Phase 5 plus a mock interview. Review due cards every day.

## 30 days · deeper pass

Allocate one day to each of the 21 topics in original phase order. Use days 22–26 for cross-topic paths (Coroutines → Flow → Compose; Lifecycle → Memory → Background Work; Architecture → SOLID → DI → Modules; Security → Payments → System Design; Testing → CI/CD → Release). Use days 27–30 for due reviews, two timed mocks, and weak areas.
