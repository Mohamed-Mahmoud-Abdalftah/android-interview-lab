## How to Study

1. Understand the runtime mental model and trace execution step by step.
2. Predict code output and failure behavior before checking the solution.
3. Formulate your spoken response aloud, then contrast with Quick (~30s), Best (60–90s), and Deep (2–3m) answers.
4. Run hands-on code challenges and track your progress right from the page.

> Progress, bookmarks, and notes are saved locally in your browser (`localStorage`). JSON export and import let you sync across machines without any external backend.
