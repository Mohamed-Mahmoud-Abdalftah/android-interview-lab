# UI-003 revision cards

1. **LaunchedEffect keys:** Keys define effect identity; a change cancels the old coroutine and starts a new one.
2. **DisposableEffect cleanup:** Register and unregister the same observer at a lifecycle-aware boundary.
3. **rememberUpdatedState:** Keep a long-lived effect while reading the latest callback or value without an unnecessary restart.
4. **Lifecycle-aware collection:** Collect UI state only while the chosen lifecycle is active and use the correct owner.
5. **Effect testing:** Change keys and lifecycle deterministically and assert start, cancellation, and exactly-once cleanup.
