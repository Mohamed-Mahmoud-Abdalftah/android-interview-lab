# PRO-001 revision cards

Use after [PRO-001](../06-Production-Engineering/pro-001-room-migrations-wal-and-datastore.md).

<ol dir="rtl" lang="ar"><li><strong>migration coverage معناها إيه؟</strong> كل installed schema مدعومة عندها path مختبرة للtarget.</li><li><strong>اختبر الشكل بس؟</strong> لأ؛ اختبر rows والconstraints والindexes وسلوك DAO.</li><li><strong>WAL يضمن إيه؟</strong> يساعد readers تتداخل مع writer؛ لا يعمل parallel writers ولا remote consistency.</li><li><strong>network جوه transaction؟</strong> لأ؛ خزّن intent محليًا، اقفل transaction، نفّذ network، وطبّق الرد بشروط.</li><li><strong>Room ولا DataStore؟</strong> Room للعلاقات والاستعلامات والمعاملات؛ DataStore لإعدادات صغيرة.</li><li><strong>destructive migration؟</strong> فقط لبيانات disposable بعقد recovery واضح.</li><li><strong>JVM planner يثبت إيه؟</strong> graph coverage المعلنة، مش SQL أو Room أو process death.</li></ol>
