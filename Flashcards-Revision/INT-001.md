# INT-001 revision cards

1. **Capstone boundaries:** UI sends intent, repository commits local truth, outbox syncs, and session scopes account data.
2. **Test portfolio:** Use reducer unit tests, persistence migration tests, worker integration, and UI journeys for distinct risks.
3. **Failure injection:** Force process death, network loss, conflict, account switch, duplicate work, and stale completion.
4. **Observability contract:** Trace operation identity and stage without note content or credentials.
5. **Toolchain honesty:** Architecture and JVM models remain separate from an Android build until SDK evidence exists.
