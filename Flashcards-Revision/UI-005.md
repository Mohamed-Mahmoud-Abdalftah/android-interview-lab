# UI-005 revision cards

1. **Adaptive breakpoints:** Choose layouts from available window space and content needs, preserving state across layout changes.
2. **RTL correctness:** Use logical directions and isolate code, numbers, and icons whose meaning is directional.
3. **Accessibility semantics:** Expose role, label, state, action, focus order, and sufficiently large targets without duplicate noise.
4. **Font-scale resilience:** Content must reflow, scroll, or wrap without clipping critical actions.
5. **UI performance evidence:** Measure frame timing and expensive phases on representative release builds before optimizing.
