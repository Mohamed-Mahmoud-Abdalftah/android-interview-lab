# AND-003 revision cards

1. **Task and back-stack semantics:** Launch modes control Activity instance and task behavior, but they do not define business navigation or typed arguments. I model destinations and test Back from real entry points.
2. **Intent input validation:** Exported boundaries can be invoked externally. Validate action, origin shape, required fields, sizes, and authorization again inside the component.
3. **PendingIntent mutability:** Use immutable unless the receiving workflow requires a documented fill-in field. Build stable request identity so two actions do not unexpectedly replace each other.
4. **Exported component review:** Inspect who must call it, required permission, intent filters, sensitive operations, input validation, and whether an internal non-exported proxy is possible.
5. **Deep-link authentication:** Treat the link as navigation intent, preserve only safe destination identity, route through authentication, then re-authorize the order for the active account before display.
