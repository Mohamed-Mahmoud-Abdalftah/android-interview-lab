# AND-006 revision cards

1. **Evidence-tool selection:** Use Perfetto and ANR stacks for timing and thread state, logcat for correlated events, dumpsys for snapshots, and bugreport for broader system context. Each answers a different question.
2. **ANR triage sequence:** Confirm ANR type and time, locate the process and main stack, classify running versus blocked, follow lock or Binder ownership, then compare repeated traces and recent release changes.
3. **Reproduction matrix:** Choose dimensions that separate hypotheses: fresh versus restored, process alive versus recreated, foreground versus background, and network state. Start pairwise and add only evidence-driven cases.
4. **Stack live-coding invariant:** After consuming a prefix, the stack contains unmatched opening brackets in encounter order. A closing bracket must match the top; the final stack must be empty.
5. **Evidence communication:** Separate observation, inference, and decision. State what the trace proves, competing explanations, the next discriminating test, and the reversible mitigation.
