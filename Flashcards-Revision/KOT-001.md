# KOT-001 revision card

Linked [lesson](../01-Kotlin-JVM-ART/KOT-001-nullability-java-boundary.md). Review next day, days 3, 7, 14, and 30 if this topic remains weak.

1. What does `String?` express? **The value may be null.**
2. What is `String!`? **Tool notation for a Java platform type; it is not source syntax.**
3. Why does a direct call on a platform type compile? **Kotlin relaxes null checks because the Java contract is unknown.**
4. What does `?.` handle? **Null propagation for one expression, not blank or malformed data.**
5. What does a local snapshot solve? **It prevents a check and use from reading a mutable property twice.**
6. Why test the Java fake returning null? **A compile-time Kotlin type cannot prove the vendor's runtime behavior.**
