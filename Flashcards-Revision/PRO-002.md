# PRO-002 revision cards

1. **Timeout taxonomy:** Connect, read, call, and application deadlines have different meanings and ownership.
2. **Retry safety:** Retry only classified transient failures and only when operation semantics are safe or idempotent.
3. **Token refresh single-flight:** Concurrent 401 responses share one refresh result and avoid recursive authentication loops.
4. **Unknown outcome:** A timed-out write may have committed; represent unknown and reconcile by operation identity.
5. **Backoff and jitter:** Bound exponential delay, add jitter, honor server guidance, and stop on permanent failure.
