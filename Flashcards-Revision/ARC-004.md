# ARC-004 revision cards

1. **Hilt component lifetimes:** Scope lifetime must match the data owner; a singleton cannot safely retain account-scoped mutable state.
2. **Qualifier design:** Qualifiers distinguish semantic bindings such as Authenticated and Public clients, not arbitrary implementation names.
3. **Accidental singleton session:** Logout must invalidate account state; process-wide caches need keys or explicit clearing and must not capture screen owners.
4. **DI replacement tests:** A test replaces the narrow boundary and verifies graph wiring plus behavior; constructor tests alone do not prove Hilt installation.
5. **Service locator trade-off:** A global locator hides dependencies and lifetime, making order-dependent tests and stale state easier to create.
