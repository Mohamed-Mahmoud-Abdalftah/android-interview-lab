# UI-006 revision cards

1. **UI test pyramid:** Put pure state transitions in unit tests and reserve device tests for framework and user integration.
2. **Semantics selectors:** Select by stable meaning, not incidental layout hierarchy or translated display text.
3. **Accessibility assertions:** Semantics tests catch labels and actions, while TalkBack and visual checks cover additional behavior.
4. **Flakiness removal:** Control clocks, dispatchers, network, and state instead of increasing sleeps.
5. **Sliding-window invariant:** Maintain exactly the elements satisfying the current window contract and update both ends once.
