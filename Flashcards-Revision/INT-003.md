# INT-003 revision cards

1. **Risk prioritization:** Rank by user impact, exploitability or frequency, evidence confidence, and reversibility.
2. **Trust boundaries:** Map external intents, network, storage, IPC, WebView, vendor SDKs, and backend authority.
3. **Release-like performance:** Measure representative journeys and percentiles on controlled release builds.
4. **Security regression tests:** Test authorization, hostile inputs, redaction, exported surfaces, and dependency configuration.
5. **Trade-off communication:** State the protected invariant, measured cost, alternatives, and rollback signal.
