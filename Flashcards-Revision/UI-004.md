# UI-004 revision cards

1. **Back-stack ownership:** The navigation host owns ordered entries; screens should request navigation rather than mutate hidden globals.
2. **Typed arguments:** Pass stable identifiers and reload current data instead of serializing domain objects into routes.
3. **singleTop semantics:** singleTop prevents an equal destination at the top, not duplicates elsewhere or stale arguments.
4. **Deep-link entry:** A deep link must build an authorized valid stack and preserve Back behavior.
5. **Navigation testing:** Assert destinations and arguments from each entry point, recreation, duplicate taps, and invalid links.
