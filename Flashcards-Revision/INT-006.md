# INT-006 revision cards

1. **Readiness evidence:** Require an explanation, trace, implementation, tests, and trade-off defense for each core domain.
2. **Gap-driven revision:** Prioritize errors and slow explanations, then retest after spaced intervals.
3. **Mock interpretation:** Use rubric categories and examples; one score never proves hiring outcome.
4. **Portfolio honesty:** Distinguish executed Android evidence, JVM models, reviewed syntax, and conceptual designs.
5. **Interview-day strategy:** Clarify, state assumptions, think aloud, test boundaries, and summarize the decision.
