# SYS-004 revision cards

1. **Source of truth:** UI observes local canonical state while sync updates it through transactions.
2. **Durable outbox:** Persist mutation and local state atomically so process death cannot lose intent.
3. **Conflict policy:** Choose per-domain semantics and preserve both evidence and user intent when automatic merge is unsafe.
4. **Deletion tombstones:** A durable deletion marker prevents an older remote copy from resurrecting data.
5. **Sync observability:** Track pending age, retry reason, conflicts, and success without logging note content.
