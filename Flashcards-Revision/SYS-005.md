# SYS-005 revision cards

1. **Push as signal:** A push is a delivery hint; fetch or reconcile canonical data and handle duplicates.
2. **Ordering and gaps:** Use server sequence or cursor, detect gaps, and backfill before presenting a complete history.
3. **Reconnect policy:** Backoff with jitter, network awareness, token refresh, and one active connection owner.
4. **Location freshness:** Expose timestamp and accuracy, adapt rate to user value, and stop collection with owner lifetime.
5. **Privacy and observability:** Minimize retention and precision, obtain permission, and separate health metadata from sensitive content.
