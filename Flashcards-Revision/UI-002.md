# UI-002 revision cards

1. **State reads and invalidation:** Compose tracks observable state reads and schedules affected scopes when values change.
2. **State hoisting:** Hoist state as value plus events to the lowest common owner that needs coordination.
3. **Immutable collections:** Publishing immutable snapshots makes equality and change ownership auditable.
4. **Stability and skipping:** Stability can enable skipping, but false stability declarations can hide changes and break UI.
5. **Recomposition evidence:** Use layout inspector or tracing and measure expensive work; counts alone are not a user problem.
