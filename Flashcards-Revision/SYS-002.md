# SYS-002 revision cards

1. **BFS and DFS choice:** BFS gives shortest edge count in an unweighted graph; DFS fits reachability and recursive structure with depth risks.
2. **Heap invariant:** The root is the priority optimum; arbitrary iteration is not globally sorted.
3. **Dijkstra precondition:** Weights must be non-negative and stale heap entries need handling.
4. **Dynamic-programming state:** Define exactly what dp state means, recurrence, base cases, and evaluation order.
5. **Graph test boundaries:** Cover cycles, self-loops, disconnected nodes, duplicate edges, overflow, and invalid weights.
