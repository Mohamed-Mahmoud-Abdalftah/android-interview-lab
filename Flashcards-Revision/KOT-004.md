# KOT-004 revision cards

Review after [Day 4](../01-Kotlin-JVM-ART/kot-004-functions-lambdas-and-closures.md), then approximately next day and days 7, 14 and 30 if weak. Answers are visible.

<ol dir="rtl" lang="ar">
<li><strong>الـ lambda بتتنفذ وقت كتابتها؟</strong> لأ؛ وقت caller يناديها، إلا لو higher-order function نادتها فورًا.</li>
<li><strong>الـ closure دايمًا snapshot؟</strong> لأ؛ captured <code dir="ltr">var</code> ممكن تتغير قبل الاستدعاء، بينما <code dir="ltr">val snapshot</code> ثابتة.</li>
<li><strong>إمتى تحتفظ بـ event ID؟</strong> لو العقد عن الحدث الأصلي؛ اقرأ current state وقت التنفيذ لو العقد عن أحدث اختيار.</li>
<li><strong>هل trailing lambda معناها async؟</strong> لأ؛ دي syntax، والتوقيت تحدده function المستقبلة.</li>
<li><strong>هل provider read واحدة تمنع race أو stale response؟</strong> لأ؛ هي تثبّت قيمة invocation فقط.</li>
<li><strong>إيه معنى true في المعمل؟</strong> callback الطلب اتنادت؛ لا تعني نجاح network.</li>
</ol>
