# COR-006 revision cards

1. **runTest and virtual time:** runTest provides a TestScope, tracks child coroutines, skips compatible delays through virtual time, and reports unfinished work. It makes scheduling controllable instead of coupling assertions to machine speed.
2. **One scheduler rule:** A shared scheduler gives one virtual clock and one queue, so advance and runCurrent control all subject work consistently. Separate schedulers can leave work invisible to the test's clock.
3. **Testing hot flows:** Read value for current state, use take or first for a bounded expectation, or launch a collector in backgroundScope and cancel it. The test must own collector lifetime.
4. **Hash-map invariant:** Before index i, the map contains values from earlier indices and their chosen indices. I ask whether target minus current exists before inserting current, which prevents using the same element twice and returns according to the specified index policy.
5. **Flaky test diagnosis:** I inspect leaked scopes, shared mutable fakes, real dispatchers, wall-clock waits, and global Main replacement cleanup. I reproduce with ordering and repetition, then remove the uncontrolled dependency rather than increasing sleeps.
