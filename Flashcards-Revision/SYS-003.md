# SYS-003 revision cards

1. **Session state machine:** Model signed out, authenticating, active, refreshing, and reauthentication-required with explicit transitions.
2. **Refresh race:** A refresh result is accepted only for the current account generation and cannot revive a logged-out session.
3. **Secure storage:** Keystore protects key material; it does not make arbitrary stored plaintext or server trust unnecessary.
4. **Account partitioning:** Database rows, caches, work, and notifications must carry account identity and clear or switch atomically.
5. **Server authority:** The backend validates authorization and revocation; client checks improve UX but are not final security.
