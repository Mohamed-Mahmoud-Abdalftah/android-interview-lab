# KOT-003 revision cards

Use after [Day 3](../01-Kotlin-JVM-ART/kot-003-classes-constructors-initialization-order.md), then approximately next day, day 7, 14 and 30 if weak. Answers are visible.

<ol dir="rtl" lang="ar">
<li><strong>ترتيب <code dir="ltr">property initializer</code> و<code dir="ltr">init</code>؟</strong> حسب ظهورهم في class body.</li>
<li><strong>هل secondary body يسبق primary؟</strong> لأ؛ التفويض والتهيئة الأساسية أولًا.</li>
<li><strong>هل parameter من غير <code dir="ltr">val/var</code> property؟</strong> لأ؛ خزّنه صراحة لو محتاجه.</li>
<li><strong>متى تستخدم <code dir="ltr">require</code>؟</strong> لعقد إنشاء يعتبر input غير صالح خطأ، مع factory لخطأ خارجي متوقع.</li>
<li><strong>ليه <code dir="ltr">open</code> call في base init خطر؟</strong> ممكن يدخل override قبل derived fields تتجهز.</li>
<li><strong>هل نجاح constructor يثبت اتصال الشبكة؟</strong> لأ؛ صحة شكل القيمة منفصلة عن side effect خارجي.</li>
</ol>
