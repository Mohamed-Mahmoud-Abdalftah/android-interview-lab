# UI-Q017 — Typed arguments

## Interview question

> **Interviewer:** A navigation route passes a full User object as encoded JSON. Review the design and replace it with typed, validated identifiers and source-of-truth reload.

<p dir="rtl" lang="ar"><strong>السياق:</strong> نفس detail route تتضاف مرتين مع نفس ID، أو object كبيرة في arguments تبقى stale بعد process death.</p>

## Follow-ups an interviewer may ask

1. What is the most common wrong answer here, and what production failure can it cause?
2. What exact test or trace would convince you that the fix works?
3. Under which constraint would you choose a different design?
