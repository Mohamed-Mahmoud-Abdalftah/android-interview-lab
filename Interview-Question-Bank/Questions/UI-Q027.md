# UI-Q027 — Semantics selectors

## Interview question

> **Interviewer:** A test finds nodes by visible text and breaks after translation. Replace brittle selectors without hiding accessibility defects behind arbitrary test tags.

<p dir="rtl" lang="ar"><strong>السياق:</strong> اختبار يعتمد على text متغيرة وترتيب زمني وsleep، أو screenshot تعتبر accessibility proof.</p>

## Follow-ups an interviewer may ask

1. What is the most common wrong answer here, and what production failure can it cause?
2. What exact test or trace would convince you that the fix works?
3. Under which constraint would you choose a different design?
