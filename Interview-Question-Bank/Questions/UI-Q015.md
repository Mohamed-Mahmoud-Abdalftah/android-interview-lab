# UI-Q015 — Effect testing

## Interview question

> **Interviewer:** Design a deterministic test proving an effect restarts when its key changes, cleans up once, and uses the latest callback without relying on delays.

<p dir="rtl" lang="ar"><strong>السياق:</strong> LaunchedEffect(Unit) تقرأ userId قديمة، أو key متغيرة كل frame تعيد network request، أو collector تستمر بعد view STOPPED.</p>

## Follow-ups an interviewer may ask

1. What is the most common wrong answer here, and what production failure can it cause?
2. What exact test or trace would convince you that the fix works?
3. Under which constraint would you choose a different design?
