# UI-Q021 — Adaptive breakpoints

## Interview question

> **Interviewer:** A tablet changes from split screen to full screen while a detail item is selected. Design adaptive layout from window size without losing selection or duplicating navigation state.

<p dir="rtl" lang="ar"><strong>السياق:</strong> layout ثابتة تنهار عند 200% font، icon اتجاهها غلط في RTL، أو تحسين يخفي semantics عشان يقلل nodes.</p>

## Follow-ups an interviewer may ask

1. What is the most common wrong answer here, and what production failure can it cause?
2. What exact test or trace would convince you that the fix works?
3. Under which constraint would you choose a different design?
