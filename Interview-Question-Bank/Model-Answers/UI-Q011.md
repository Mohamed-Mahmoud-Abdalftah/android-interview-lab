# UI-Q011 — Complete model answer

## الإجابة المختصرة

**Spoken answer:** “Keys define effect identity; a change cancels the old coroutine and starts a new one.”

<p dir="rtl" lang="ar"><strong>الخلاصة بالمصري:</strong> effect identity تحددها keys، التسجيل له cleanup مطابق، والcallback الحديثة تُقرأ من غير restart غير مطلوب.</p>

## افهم السؤال قبل ما تجاوب

<p dir="rtl" lang="ar"><strong>المحاور بيديك الحالة دي:</strong> <bdi dir="ltr">LaunchedEffect(Unit) collects data for user A, then the same destination displays user B. Explain the stale work and choose keys and ownership that restart exactly when intended.</bdi></p>

<p dir="rtl" lang="ar"><strong>تحت الغطا في LaunchedEffect keys:</strong> LaunchedEffect تربط coroutine بمجموعة keys؛ تغير key يلغي القديمة ويبدأ جديدة. DisposableEffect تربط register/unregister بنفس lifetime. rememberUpdatedState تغير القيمة المقروءة داخل effect طويلة من غير restart.</p>

<p dir="rtl" lang="ar"><strong>إيه اللي لازم يظهر في إجابتك؟</strong> حدّد الـowner، امشِ في الـexecution order، سمّي الـfailure اللي السؤال كاشفها، وبعدها اربط القرار بـtrade-off واختبار يثبت السلوك.</p>

## القرار العملي

<p dir="rtl" lang="ar">بالنسبة لـLaunchedEffect keys: اختار keys تمثل lifetime الحقيقي، استخدم DisposableEffect للregister/unregister وrememberUpdatedState للقيمة الحديثة داخل effect طويلة.</p>

## الـfailure والـwrong answer

**Common wrong answer:** “Use Unit as every effect key and read whatever callback was captured initially.”

<p dir="rtl" lang="ar">في <strong>LaunchedEffect keys</strong> المشكلة في الإجابة دي إنها تكسر الـinvariant الأساسية: effect identity تحددها keys، التسجيل له cleanup مطابق، والcallback الحديثة تُقرأ من غير restart غير مطلوب. النتيجة ممكن تبان سليمة في الـhappy path، وبعد race أوrecreation أوfailure boundary تظهر المشكلة الحقيقية.</p>

## الـtrade-off

<p dir="rtl" lang="ar">في LaunchedEffect keys: event handler عادية أفضل لو مفيش lifecycle side effect؛ متستخدمش Effect API لنقل pure calculation.</p>

## الاختبار اللي يثبت الإجابة

<p dir="rtl" lang="ar">لاختبار LaunchedEffect keys: غيّر key وcallback وlifecycle بترتيب متحكم، واثبت start/cancel/cleanup مرة واحدة وعدم callback على owner متوقفة.</p>
