## Live-coding version

**Problem:** Given `[2, 1, 5, 1, 3, 2]` and `k=3`, return maximum sum `9`.

```kotlin
fun maxWindowSum(values: IntArray, k: Int): Long {
    require(k in 1..values.size)
    var window = values.take(k).sumOf(Int::toLong)
    var best = window
    for (right in k until values.size) {
        window += values[right].toLong() - values[right - k].toLong()
        best = maxOf(best, window)
    }
    return best
}
```

<p dir="rtl" lang="ar"><strong>Trace وcomplexity:</strong> قبل تحديث best، window تمثل بالضبط آخر k عناصر. كل عنصر يدخل مرة ويخرج مرة، فالوقت O(n) والـextra space O(1).</p>
