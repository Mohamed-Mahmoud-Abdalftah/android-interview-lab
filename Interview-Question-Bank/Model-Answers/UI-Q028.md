# UI-Q028 — Complete model answer

## الإجابة المختصرة

**Spoken answer:** “Semantics tests catch labels and actions, while TalkBack and visual checks cover additional behavior.”

<p dir="rtl" lang="ar"><strong>الخلاصة بالمصري:</strong> كل interactive node تعرض role وlabel وstate وaction صحيحة، والـfocus order يفضل منطقي؛ screenshot لا تثبت TalkBack behavior.</p>

## افهم السؤال قبل ما تجاوب

<p dir="rtl" lang="ar"><strong>المحاور بيديك الحالة دي:</strong> <bdi dir="ltr">A screenshot matches the design. List the accessibility claims it cannot prove and write the semantic assertions and manual checks still required.</bdi></p>

<p dir="rtl" lang="ar"><strong>تحت الغطا في Accessibility assertions:</strong> الـlayout تختار من available window size وتستخدم start/end بدل left/right. semantics tree هي الواجهة اللي TalkBack والtests تقرأها، وممكن تختلف عن pixels. font scale وfocus order جزء من functional correctness، مش polish.</p>

<p dir="rtl" lang="ar"><strong>إيه اللي لازم يظهر في إجابتك؟</strong> حدّد الـowner، امشِ في الـexecution order، سمّي الـfailure اللي السؤال كاشفها، وبعدها اربط القرار بـtrade-off واختبار يثبت السلوك.</p>

## القرار العملي

<p dir="rtl" lang="ar">بالنسبة لـAccessibility assertions: استخدم stable semantics selectors مع controlled state، اختبر role/state/action، وبعدها نفّذ TalkBack وfont-scale وfocus journey على Android.</p>

## الـfailure والـwrong answer

**Common wrong answer:** “The screenshot matches the design, so accessibility is covered.”

<p dir="rtl" lang="ar">في <strong>Accessibility assertions</strong> المشكلة في الإجابة دي إنها تكسر الـinvariant الأساسية: كل interactive node تعرض role وlabel وstate وaction صحيحة، والـfocus order يفضل منطقي؛ screenshot لا تثبت TalkBack behavior. النتيجة ممكن تبان سليمة في الـhappy path، وبعد race أوrecreation أوfailure boundary تظهر المشكلة الحقيقية.</p>

## الـtrade-off

<p dir="rtl" lang="ar">في Accessibility assertions: Screenshot مناسبة للpixels فقط؛ manual أو automated accessibility journey مطلوبة لما الخطر في focus أو announcement.</p>

## الاختبار اللي يثبت الإجابة

<p dir="rtl" lang="ar">لاختبار Accessibility assertions: اختبار semantics يفشل لو label أو action ناقصة، ثم device test عند 200% font scale وRTL وTalkBack يثبت إن الـfocus والannouncement صح.</p>
