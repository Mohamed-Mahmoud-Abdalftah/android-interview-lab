# UI-Q023 — Complete model answer

## الإجابة المختصرة

**Spoken answer:** “Expose role, label, state, action, focus order, and sufficiently large targets without duplicate noise.”

<p dir="rtl" lang="ar"><strong>الخلاصة بالمصري:</strong> كل interactive node تعرض role وlabel وstate وaction صحيحة، والـfocus order يفضل منطقي؛ screenshot لا تثبت TalkBack behavior.</p>

## افهم السؤال قبل ما تجاوب

<p dir="rtl" lang="ar"><strong>المحاور بيديك الحالة دي:</strong> <bdi dir="ltr">An icon-only toggle looks correct but TalkBack announces only 'button'. Define the role, label, state, action, and tests needed for a usable control.</bdi></p>

<p dir="rtl" lang="ar"><strong>تحت الغطا في Accessibility semantics:</strong> الـlayout تختار من available window size وتستخدم start/end بدل left/right. semantics tree هي الواجهة اللي TalkBack والtests تقرأها، وممكن تختلف عن pixels. font scale وfocus order جزء من functional correctness، مش polish.</p>

<p dir="rtl" lang="ar"><strong>إيه اللي لازم يظهر في إجابتك؟</strong> حدّد الـowner، امشِ في الـexecution order، سمّي الـfailure اللي السؤال كاشفها، وبعدها اربط القرار بـtrade-off واختبار يثبت السلوك.</p>

## القرار العملي

<p dir="rtl" lang="ar">بالنسبة لـAccessibility semantics: استخدم stable semantics selectors مع controlled state، اختبر role/state/action، وبعدها نفّذ TalkBack وfont-scale وfocus journey على Android.</p>

## الـfailure والـwrong answer

**Common wrong answer:** “The screenshot matches the design, so accessibility is covered.”

<p dir="rtl" lang="ar">في <strong>Accessibility semantics</strong> المشكلة في الإجابة دي إنها تكسر الـinvariant الأساسية: كل interactive node تعرض role وlabel وstate وaction صحيحة، والـfocus order يفضل منطقي؛ screenshot لا تثبت TalkBack behavior. النتيجة ممكن تبان سليمة في الـhappy path، وبعد race أوrecreation أوfailure boundary تظهر المشكلة الحقيقية.</p>

## الـtrade-off

<p dir="rtl" lang="ar">في Accessibility semantics: Screenshot مناسبة للpixels فقط؛ manual أو automated accessibility journey مطلوبة لما الخطر في focus أو announcement.</p>

## الاختبار اللي يثبت الإجابة

<p dir="rtl" lang="ar">لاختبار Accessibility semantics: اختبار semantics يفشل لو label أو action ناقصة، ثم device test عند 200% font scale وRTL وTalkBack يثبت إن الـfocus والannouncement صح.</p>
