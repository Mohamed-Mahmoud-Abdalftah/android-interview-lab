# UI-Q020 — Complete model answer

## الإجابة المختصرة

**Spoken answer:** “Assert destinations and arguments from each entry point, recreation, duplicate taps, and invalid links.”

<p dir="rtl" lang="ar"><strong>الخلاصة بالمصري:</strong> Navigation host تملك ordered entries؛ route تحمل stable IDs فقط، وكل entry point يبني authorized stack وBack behavior متوقع.</p>

## افهم السؤال قبل ما تجاوب

<p dir="rtl" lang="ar"><strong>المحاور بيديك الحالة دي:</strong> <bdi dir="ltr">What belongs in a pure navigation policy test, a NavController integration test, and a device deep-link test? Give one failure each layer can catch.</bdi></p>

<p dir="rtl" lang="ar"><strong>تحت الغطا في Navigation testing:</strong> NavHost تملك sequence من back-stack entries، وكل entry لها lifecycle وSavedStateHandle. route المفروض تحمل ID صغيرة لاobject stale؛ singleTop يقارن القمة فقط، وdeep link لازم تبني stack منطقية بعد validation وauthorization.</p>

<p dir="rtl" lang="ar"><strong>إيه اللي لازم يظهر في إجابتك؟</strong> حدّد الـowner، امشِ في الـexecution order، سمّي الـfailure اللي السؤال كاشفها، وبعدها اربط القرار بـtrade-off واختبار يثبت السلوك.</p>

## القرار العملي

<p dir="rtl" lang="ar">بالنسبة لـNavigation testing: عرّف typed route، reload data بالID، اختار singleTop/popUpTo من UX، ومرر external entry عبر validation وauth قبل destination.</p>

## الـfailure والـwrong answer

**Common wrong answer:** “Passing the whole domain object and adding singleTop solves stale arguments and all duplicates.”

<p dir="rtl" lang="ar">في <strong>Navigation testing</strong> المشكلة في الإجابة دي إنها تكسر الـinvariant الأساسية: Navigation host تملك ordered entries؛ route تحمل stable IDs فقط، وكل entry point يبني authorized stack وBack behavior متوقع. النتيجة ممكن تبان سليمة في الـhappy path، وبعد race أوrecreation أوfailure boundary تظهر المشكلة الحقيقية.</p>

## الـtrade-off

<p dir="rtl" lang="ar">في Navigation testing: singleTop يمنع duplicate في القمة فقط؛ state-based navigation أو popUpTo أوضح لما المطلوب إزالة history أوسع.</p>

## الاختبار اللي يثبت الإجابة

<p dir="rtl" lang="ar">لاختبار Navigation testing: شغّل normal launch وdeep link وnotification وduplicate taps ثم recreation؛ تحقق من entries والarguments وBack وinvalid link rejection.</p>
