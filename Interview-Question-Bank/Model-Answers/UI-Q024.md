# UI-Q024 — Complete model answer

## الإجابة المختصرة

**Spoken answer:** “Content must reflow, scroll, or wrap without clipping critical actions.”

<p dir="rtl" lang="ar"><strong>الخلاصة بالمصري:</strong> نفس state تحافظ على meaning وfocus وcritical actions عبر width وRTL وfont scale؛ الاختبار يختار semantics ثابتة ويتحكم في الوقت والبيانات.</p>

## افهم السؤال قبل ما تجاوب

<p dir="rtl" lang="ar"><strong>المحاور بيديك الحالة دي:</strong> <bdi dir="ltr">At 200% font scale, a checkout button overlaps the total. Redesign the layout and state what must scroll, wrap, remain reachable, and be tested.</bdi></p>

<p dir="rtl" lang="ar"><strong>تحت الغطا في Font-scale resilience:</strong> الـlayout تختار من available window size وتستخدم start/end بدل left/right. semantics tree هي الواجهة اللي TalkBack والtests تقرأها، وممكن تختلف عن pixels. font scale وfocus order جزء من functional correctness، مش polish.</p>

<p dir="rtl" lang="ar"><strong>إيه اللي لازم يظهر في إجابتك؟</strong> حدّد الـowner، امشِ في الـexecution order، سمّي الـfailure اللي السؤال كاشفها، وبعدها اربط القرار بـtrade-off واختبار يثبت السلوك.</p>

## القرار العملي

<p dir="rtl" lang="ar">بالنسبة لـFont-scale resilience: استخدم available window size وlogical start/end، خلّي المحتوى reflow/scroll، اختبر pure state محليًا وframework behavior على device بقياسات frames.</p>

## الـfailure والـwrong answer

**Common wrong answer:** “A phone screenshot and a fixed delay prove adaptive, RTL, accessible, and stable UI behavior.”

<p dir="rtl" lang="ar">في <strong>Font-scale resilience</strong> المشكلة في الإجابة دي إنها تكسر الـinvariant الأساسية: نفس state تحافظ على meaning وfocus وcritical actions عبر width وRTL وfont scale؛ الاختبار يختار semantics ثابتة ويتحكم في الوقت والبيانات. النتيجة ممكن تبان سليمة في الـhappy path، وبعد race أوrecreation أوfailure boundary تظهر المشكلة الحقيقية.</p>

## الـtrade-off

<p dir="rtl" lang="ar">في Font-scale resilience: golden screenshot تكشف pixels لكنها لا تثبت focus/announcement؛ semantics/device journey تكمل الدليل.</p>

## الاختبار اللي يثبت الإجابة

<p dir="rtl" lang="ar">لاختبار Font-scale resilience: غطّ LTR/RTL و200% font وcompact/expanded وkeyboard/TalkBack، واستخدم controlled clocks/network من غير sleeps أو selectors مرتبطة بالlayout.</p>
