# UI-Q029 — Complete model answer

## الإجابة المختصرة

**Spoken answer:** “Control clocks, dispatchers, network, and state instead of increasing sleeps.”

<p dir="rtl" lang="ar"><strong>الخلاصة بالمصري:</strong> نفس state تحافظ على meaning وfocus وcritical actions عبر width وRTL وfont scale؛ الاختبار يختار semantics ثابتة ويتحكم في الوقت والبيانات.</p>

## افهم السؤال قبل ما تجاوب

<p dir="rtl" lang="ar"><strong>المحاور بيديك الحالة دي:</strong> <bdi dir="ltr">A UI test waits two seconds after tapping Save and fails in CI. Replace the delay with controlled dependencies and a semantic condition tied to the actual state transition.</bdi></p>

<p dir="rtl" lang="ar"><strong>تحت الغطا في Flakiness removal:</strong> الـflaky UI test غالبًا تعتمد على clock أوdispatcher أوnetwork أوanimation غير متحكم فيها. الحل inject هذه dependencies وتنتظر semantic condition محددة؛ sleep أطول يوسع الاحتمال ولا يثبت إن الحالة المطلوبة وصلت.</p>

<p dir="rtl" lang="ar"><strong>إيه اللي لازم يظهر في إجابتك؟</strong> حدّد الـowner، امشِ في الـexecution order، سمّي الـfailure اللي السؤال كاشفها، وبعدها اربط القرار بـtrade-off واختبار يثبت السلوك.</p>

## القرار العملي

<p dir="rtl" lang="ar">بالنسبة لـFlakiness removal: استخدم available window size وlogical start/end، خلّي المحتوى reflow/scroll، اختبر pure state محليًا وframework behavior على device بقياسات frames.</p>

## الـfailure والـwrong answer

**Common wrong answer:** “A phone screenshot and a fixed delay prove adaptive, RTL, accessible, and stable UI behavior.”

<p dir="rtl" lang="ar">في <strong>Flakiness removal</strong> المشكلة في الإجابة دي إنها تكسر الـinvariant الأساسية: نفس state تحافظ على meaning وfocus وcritical actions عبر width وRTL وfont scale؛ الاختبار يختار semantics ثابتة ويتحكم في الوقت والبيانات. النتيجة ممكن تبان سليمة في الـhappy path، وبعد race أوrecreation أوfailure boundary تظهر المشكلة الحقيقية.</p>

## الـtrade-off

<p dir="rtl" lang="ar">في Flakiness removal: golden screenshot تكشف pixels لكنها لا تثبت focus/announcement؛ semantics/device journey تكمل الدليل.</p>

## الاختبار اللي يثبت الإجابة

<p dir="rtl" lang="ar">لاختبار Flakiness removal: غطّ LTR/RTL و200% font وcompact/expanded وkeyboard/TalkBack، واستخدم controlled clocks/network من غير sleeps أو selectors مرتبطة بالlayout.</p>
